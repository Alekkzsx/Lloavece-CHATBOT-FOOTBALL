# ============================================================
# ARQUIVOS DE CONHECIMENTO — ASSISTENTE DE FUTEBOL
# ============================================================
#
# Esta pasta guarda textos sobre futebol para uma futura integração com o
# programa Java. A demonstração atual, em src/futebol/, ainda NÃO lê estes
# arquivos nem usa seu conteúdo para responder perguntas.
#
# COMO LER OS ARQUIVOS:
# - Os arquivos usam texto simples e codificação UTF-8.
# - Nos arquivos de assuntos, cada linha normalmente contém:
#       palavras-chave | resposta
# - O sinal | separa as palavras-chave da resposta.
# - Linhas vazias e linhas que começam com # são apenas espaços e comentários.
# - O conteúdo é material de conhecimento; as regras para interpretá-lo ainda
#   precisam ser programadas no assistente.
#
# ARQUIVOS DE TEXTO AUXILIAR:
# - texto/stopwords.txt: palavras comuns que poderão ser ignoradas.
# - texto/sinonimos.txt: apelidos que poderão apontar para um nome principal.
# - texto/interacoes.txt: exemplos de saudações, ajuda e despedidas.
# - texto/fallback.txt: respostas alternativas para perguntas sem resposta.
#   A escolha aleatória e o uso destes arquivos ainda não estão implementados.
#
# ORGANIZAÇÃO DOS ASSUNTOS:
# - clubes/: clubes brasileiros, europeus e sul-americanos.
# - competicoes/: Copas, campeonatos e outras competições.
# - estadios/: estádios conhecidos.
# - historia/: origem, história, momentos importantes e recordes.
# - jogadores/: atletas, lendas, geração atual e técnicos.
# - premiacoes/: prêmios individuais do futebol.
# - posicoes/: posições dos jogadores e formações.
# - regras/: regras, impedimento, faltas, pênaltis, VAR e mudanças.
# - selecoes/: Seleção Brasileira e outras seleções.
# - termos/: glossário, jogadas e táticas.
# - texto/: listas e mensagens auxiliares descritas acima.
#
# SOBRE O CONTEÚDO:
# - Os dados históricos foram reunidos principalmente até a temporada de 2025.
# - Algumas referências à Copa do Mundo de 2026 descrevem a edição antes de
#   haver campeão registrado.
# - Elencos e classificações mudam com frequência; por isso, o conteúdo evita
#   tratar essas informações como se fossem sempre atuais.
